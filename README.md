# Marvin Creative Studio

My portfolio for social media work, content creation, and website products.

## Files

- `index.html` — page content and project links
- `style.css` — colors, fonts, layout, and mobile styles
- `app.js` — project filters, project details, and copy-email button
- `assets/kitchen.jpg` — photo used in the Komorebi preview
- `THIRD-PARTY-NOTICES.md` — photo and font credits

## Preview it

Open index.html in your browser. No installation or build step is needed.
Google Fonts needs an internet connection; the page uses fallback fonts when offline.
The copy-email button requires HTTPS or localhost in some browsers; an email link is also available.

## Upload to GitHub

1. Extract this ZIP.
2. Create a GitHub repository.
3. Choose Add file > Upload files.
4. Upload the CONTENTS of this folder, including the assets folder. Keep index.html at the repository root.
5. Commit the files.

To host it with GitHub Pages, open the repository Settings > Pages and choose Deploy from a branch, then main and / (root). Save, then use the URL GitHub provides after deployment.

## Make changes

Edit index.html for your bio, projects, email, and links. Edit style.css for the appearance. Keep relative file paths intact so the site works under a GitHub Pages repository URL.

Komorebi Kitchen links to its published Canva demo. Its buyer-only template link is not included. AutoLab is labeled Coming soon and is not available for purchase. Product buttons currently use email inquiries; replace them with your checkout URLs when ready.

This folder contains the portfolio website, not the Komorebi Kitchen source code or a Canva template.
